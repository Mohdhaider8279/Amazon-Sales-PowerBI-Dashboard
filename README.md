## Project Overview

This project presents an interactive Amazon Sales Dashboard developed in Microsoft Power BI. The dashboard provides insights into sales performance, product categories, customer purchasing behavior, and business trends through dynamic visualizations.

The objective of this project is to transform raw sales data into meaningful business insights that can support decision-making and performance analysis.

---

## Dashboard Features

### Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Quantity Sold
- Average Customer Rating

### Visualizations
- Sales Trend Analysis
- Sales by Product Category
- Top Performing Products
- Customer Rating Analysis
- Category-wise Revenue Distribution
- Interactive Filters and Slicers

---

## Tools & Technologies Used

- Microsoft Power BI

- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## Dataset Information

The dashboard is built using an Amazon-style e-commerce sales dataset containing:

- Order ID
- Product Name
- Category
- Price
- Quantity Sold
- Total Sales
- Order Date
- Customer Rating
- Payment Method

*Note: This is a publicly available/sample dataset used for learning and portfolio purposes.*

---

## Business Insights

Some key insights generated from the dashboard:

- Identified top-performing product categories.
- Analyzed monthly sales trends.
- Evaluated customer satisfaction through ratings.
- Determined best-selling products.
- Compared sales performance across categories.
- Examined customer payment preferences.
